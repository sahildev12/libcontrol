## Rules for the sales team

1. **Only sell what is live** — see `03-product-feature-fact-sheet.md`. Do not promise the Expenses module; it is not in the application today.
2. **Plan limits are enforced in software** — Starter / Pro caps on seats, halls, and branches are real system limits.
3. **Pricing** — use figures in `04-pricing-and-plans.md` and note GST is extra unless your quote states otherwise.
4. **Custom plan** — always route to Phenomit for scoping; do not commit to custom development timelines without engineering sign-off.
