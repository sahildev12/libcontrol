# LibSpace — Competitive Talk Track

> **Positioning:** LibSpace is a **vertical** solution for reading libraries — not a horizontal CRM, not a generic billing app, not Excel.

---

## vs Paper register

| Register | LibSpace |
|----------|----------|
| One person updates | Whole team sees live map |
| No conflict detection | Cannot double-book same seat/slot |
| No search | Find student in seconds |
| No renewal alerts | Expiring plans on dashboard |
| Lost / damaged | Backed up digitally |

**Line:** *"Registers don't ping you when a plan expires. LibSpace does."*

---

## vs Excel / Google Sheets

| Sheets | LibSpace |
|--------|----------|
| Manual updates | Seat map updates on assign |
| Version conflicts | Single source of truth |
| No role-based access | Branch logins scoped |
| No trial workflow | Dedicated trial module |
| Reporting is manual | Dashboard KPIs built in |

**Line:** *"Excel is a calculator. LibSpace is an operating system for your library floor."*

---

## vs WhatsApp groups

| WhatsApp | LibSpace |
|----------|----------|
| Chat, not structure | Structured student + seat records |
| Messages get buried | Fee history on student profile |
| No seat map | Visual hall layout |
| Privacy concerns | Role-based access |
| Owner cannot report | Revenue and occupancy dashboards |

**Line:** *"Keep WhatsApp for announcements. Run the library on LibSpace."*

---

## vs Generic coaching institute software

Many "institute ERPs" focus on batches, attendance, and courses — not **fixed seat inventory**.

| Generic ERP | LibSpace |
|-------------|----------|
| Batch-centric | Seat-map-centric |
| Often expensive & heavy | Focused, faster onboarding |
| May lack trial seat flow | Trial → member built in |
| May not support custom library hours | Library hours + slot windows |

**Line:** *"If your product is a chair in a hall, you need software that starts with the chair."*

## vs Doing nothing (status quo)

| Hidden cost | Estimate |

## Unique differentiators (memorize)

1. **Seat-map-first** — not an afterthought module  
2. **Trial seat lifecycle** — assign, expire, convert  
3. **Continue seat numbering across halls** — optional, client-controlled  
4. **Indian fee patterns** — monthly/yearly/installments/partial pay  
5. **Two-panel architecture** — owner vs desk staff  
6. **Student ID cards** — professional member experience  
7. **Phenomit local support** — Hisar-based, IST hours

## When you lose a deal — learn why

| Lost reason | Action |
|-------------|--------|
| Price | Offer yearly; ROI calculator |
| Missing feature | Log for product; honest about roadmap |
| Chose competitor | Document which feature decided it |
| No urgency | Nurture — send expiry-season content before exam peaks |
| Internal build | Revisit in 6 months when build stalls |
